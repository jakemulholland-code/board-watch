Connect to Monday

Board Watch needs a Monday API token to read your boards. It's saved locally in a .env file on this machine (as MONDAY_API_TOKEN) and never leaves your computer except to talk to Monday.

  1. In monday.com, click your avatar → Developers → My access tokens.

Tracked boards

Add a board by its numeric ID or by pasting its monday.com URL — e.g. https://yourcompany.monday.com/boards/1234567890. Columns are mapped once and saved, so boards with different layouts all work.

Board setups

Save your boards + mappings to a file, or drop one back in — handy after pulling an update, or moving to a new machine. Import adds/updates boards by ID; it never removes boards you already have tracked.

Map columns

Due date and Status are required for overdue tracking. Owner / Person can be set on more than one column — if a board has separate Assignor and Assignee columns, mark both and everyone is pooled, so filtering to a person finds every task they're on. Department is optional and powers the department filter. Hours is optional and feeds the Management view's capacity chart. Completed date is optional too — map it if the board tracks when a task actually finished, and the Management view can tell on-time delivery apart from late instead of only "done or not". Task name is used for the title unless you map one to Title.

Default guesses roles from column names (Assignee/Assignor/Person/Owner → Owner / Person, Due Date → Due date, Status → Status, Name → Title, Department → Department, Hours → Hours, Completed Date → Completed date). Change any row below and it switches to Custom automatically — everything else stays as it was.

Bulk add boards

Paste board IDs or full monday.com board URLs — one per line, or separated by commas or spaces. Each is checked against the Default mapping preset so you can confirm the guesses look right before adding them all. Anything already tracked is unticked by default, since adding it here would overwrite its saved mapping.

Manage teams

Group a set of boards and people into a team, then filter the dashboard down to just their work — a task matches if it's on one of the team's boards or assigned to one of its people (either counts).
