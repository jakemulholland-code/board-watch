Connect to Monday

Board Watch needs a Monday API token to read your boards. It's saved locally in a .env file on this machine (as MONDAY_API_TOKEN) and never leaves your computer except to talk to Monday.

  1. In monday.com, click your avatar → Developers → My access tokens.
  2. Copy the token and paste it below.

Tracked boards

Add a board by its numeric ID (found in the board's URL on monday.com). Columns are mapped once and saved, so boards with different layouts all work.

Map columns

Every column starts unmapped — set each one yourself; nothing is guessed. Due date and Status are required for overdue tracking. Owner / Person can be set on more than one column — if a board has separate Assignor and Assignee columns, mark both and everyone is pooled, so filtering to a person finds every task they're on. Department is optional and powers the department filter. Task name is used for the title unless you map one to Title.
